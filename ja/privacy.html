プライバシーポリシー

最終更新日：2026年11月21日

PawShelf は、あなたの物をあなたの Mac に置いておくために作られています。このポリシーでは、アプリが何を保存し、何を送信するか、そして送信を止める方法を説明します。

Mac に残るもの

シェルフに置いたものはすべて Mac に残ります。ファイルへのリンク、ドロップした画像・テキスト・Web リンクのコピー、クリップボード履歴、設定がこれにあたります。これらはアプリのサンドボックス内に保存されます。私たちはこれらを受け取るサーバを運用しておらず、内容を見ることもできません。

匿名のクラッシュレポートと使用状況の統計

クラッシュを見つけ、どの機能が使われているかを知るため、アプリは Google Firebase（Crashlytics と Google Analytics for Firebase）を通じて匿名のレポートを送信します。レポートには「項目の追加」などのイベント名、件数、設定値、クラッシュの詳細、アプリのバージョン、macOS のバージョン、Mac の機種が含まれます。Firebase はアプリのインストールごとにランダムな識別子も割り当てます。

レポートには、ファイル名、フォルダのパス、リンク、ページのタイトル、コピーしたテキストなど、シェルフに置いた内容は一切含まれません。

送信は、アプリを初めて開いたときはオンになっています。止めるには、設定 › 一般 で「匿名のクラッシュレポートと使用状況の統計を送信」をオフにしてください。Google によるデータの扱いは firebase.google.com/support/privacy と policies.google.com/privacy で説明されています。

リンクのタイトルとアイコン

Web リンクを追加すると、タイトルとアイコンを表示するために、アプリがブラウザと同じように Mac からそのページを読み込みます。Web サイトからは通常の訪問として見えます。止めるには、設定 › 詳細 で「リンクのタイトルとアイコンを表示（ページを取得します）」をオフにしてください。

画像内の文字

画像内の文字は、Apple のデバイス上のテキスト認識で読み取ります。画像がどこかにアップロードされることはありません。止めるには、設定 › 詳細 で「画像内の文字を検索（このMac上で処理）」をオフにしてください。

クリップボード履歴

クリップボード履歴は、最近コピーした 50 件を Mac に保存します。パスワード管理アプリが非公開としたコピーは記録しません。止めるには、設定で「コピーした内容の履歴を残す」をオフにしてください。

しないこと

アカウントも広告もありません。データを販売したり広告目的で共有したりせず、ほかのアプリや Web サイトをまたいで追跡することもありません。PawShelf はアクセシビリティや画面収録の権限を求めません。

この Web サイト

この Web サイトは Cookie を使わず、アクセス解析も行わず、ほかのサイトから何も読み込みません。ホスティング事業者が一般的なサーバログを残す場合があります。
